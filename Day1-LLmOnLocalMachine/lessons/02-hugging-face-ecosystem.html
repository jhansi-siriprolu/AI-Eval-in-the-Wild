Lesson 02

The Hugging Face ecosystem, decoded

Hugging Face Hub hosts the model you're about to run. Learning to read a repo before downloading it will save you from pulling a 30GB file your Air can't hold.

The four things on the Hub you'll touch

🗂 Hub

huggingface.co/models — a searchable registry of ~1M+ model repos, each just a git repository of weight files + metadata.

📄 Model card

The README.md in every repo. Tells you license, intended use, training data, and (often) benchmark scores.

🧮 Datasets

huggingface.co/datasets — where benchmark test sets like MMLU actually live, versioned the same way as models.

🧰 Libraries

transformers, huggingface_hub, and community tools like mlx-lm that know how to load these repos.

Reading a repo name

Model repo names follow {organization}/{model-name}. The model name itself is a dense label — learn to parse it:

mlx-community/Qwen2.5-1.5B-Instruct-4bit
└─────┬──────┘ └┬─┘ └┬─┘ └┬─┘ └───┬────┘ └┬─┘
  publisher    family  gen  size   variant  quant
PieceMeaning
mlx-communityWho converted/published this build — a community org that mirrors popular models into MLX format
Qwen2.5Model family and generation, from Alibaba's Qwen team
1.5B1.5 billion parameters — directly drives memory use, see Lesson 03
InstructFine-tuned to follow chat instructions (vs. a raw "base" model that just completes text)
4bitWeights quantized to 4 bits each instead of 16/32 — roughly a 4–8x size reduction

Base vs. Instruct — pick Instruct

A base model only predicts "what text comes next" — ask it a question and it might just continue the sentence with more questions. An Instruct (or Chat) model has been fine-tuned on conversations to actually answer you. Always prefer the Instruct variant for hands-on work.

Where quantized builds come from

Most original model releases ship in 16-bit precision (bfloat16/fp16), which is too large and slow for an 8GB laptop. Community orgs re-package the same weights at lower precision for specific runtimes:

Org / suffixRuntimeTypical use
mlx-community/...Apple MLXWhat this course uses — native Apple Silicon speed
...-GGUF (e.g. TheBloke, bartowski)llama.cpp / OllamaMost portable, works on almost anything
No suffix, org = original authorPyTorch / transformersFull precision, needs the most RAM

Browsing the Hub for yourself

On huggingface.co/models, filter by Task → Text Generation, then search mlx-community to see everything already converted for your machine. Each card shows file sizes under the "Files and versions" tab — check that before you commit to a download on limited SSD space.

📝 Lab notebook

Browse the Hub for 2–3 other instruct models under 3B parameters that interest you. Note them here — you'll compare them against Qwen2.5-1.5B later.
