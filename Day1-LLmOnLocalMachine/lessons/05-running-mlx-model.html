Lesson 05 · Hands-on in Terminal

Running your first model, for real

This is the lesson where you leave the browser. Open Terminal.app on your Mac and run these commands from inside your AI Evals project folder.

⚠️ Run this in Terminal, not here

This page is static HTML — it can't execute anything on your machine. Copy each command (the "Copy" button on every code block helps) into Terminal yourself. That's the point: you're building real muscle memory with the actual tools.

Step 1 — Set up an isolated Python environment

cd ~/Documents/"AI Evals"
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip

Or just run bash scripts/01_setup_env.sh — it does exactly this plus the installs below.

Step 2 — Install MLX and the model tooling

pip install mlx mlx-lm huggingface_hub
PackageWhat it does
mlxApple's array/ML framework — runs directly on the M1's GPU via Metal
mlx-lmLanguage-model utilities on top of MLX: download, generate, chat, evaluate
huggingface_hubClient library for downloading model repos from the Hub

Step 3 — Download & smoke-test the model

python -m mlx_lm.generate \
  --model mlx-community/Qwen2.5-1.5B-Instruct-4bit \
  --prompt "In one sentence, explain why quantization helps run AI models on laptops." \
  --max-tokens 120

The first run downloads the model (~1GB) into ~/.cache/huggingface and caches it — every run after that starts instantly. Watch the printed tokens-per-second figure at the end; on an M1 Air you should see roughly 15–30 tok/s for a model this size.

Step 4 — Chat with it interactively

python scripts/03_chat_demo.py

A minimal REPL loop (in scripts/03_chat_demo.py) that keeps the model loaded between turns so you can have a real back-and-forth without reloading weights each time.

Troubleshooting

SymptomLikely fix
zsh: command not found: pythonUse python3, or make sure your venv is activated (prompt shows (.venv))
Download seems stuckLarge first download — check Activity Monitor's Network tab; safe to let it run
"Killed: 9" / process diesClose other memory-heavy apps (Chrome with many tabs is the usual culprit on 8GB); re-check Lesson 03's calculator
ModuleNotFoundError: mlxMLX requires Apple Silicon + macOS 13.5+; confirm with python -c "import platform;print(platform.machine())" → should print arm64
