Why token count matters on your hardware

💾 Memory

Every token the model has "seen" occupies space in the KV cache — more tokens in your prompt means more RAM used, as you saw in Lesson 03.

⏱ Speed

Generation happens one token at a time. A 500-token answer means 500 forward passes through the model — token count is your literal latency budget.

📏 Benchmarks

Evaluation harnesses score based on token-level probabilities — the granularity you're seeing here is exactly what perplexity (Lesson 06) is computed over.

A rule of thumb

For English text, a useful mental model is ~1 token ≈ 0.75 words (or equivalently, 100 tokens ≈ 75 words). Numbers, code, and non-English text often tokenize far less efficiently — try pasting a JSON blob or some Hindi/Telugu text above and watch the token count jump relative to word count.
