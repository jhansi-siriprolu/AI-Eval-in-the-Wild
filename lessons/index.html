Evaluating AI Models on an 8GB M1 Air

A hands-on project to learn how model evaluation actually works — by running a real, small open-weight model from Hugging Face on your own MacBook Air, and scoring it with the same benchmarks used on public leaderboards. No cloud GPU, no API keys required.

Why this hardware is actually fine

An 8GB M1 Air can comfortably run and evaluate 1–3 billion parameter models in 4-bit quantization — the same class of model many production chat features use for low-latency tasks. This course picks one to start:

Model mlx-community/Qwen2.5-1.5B-Instruct-4bit ~1.0 GB on disk Fits with headroom

You'll see exactly why this model was chosen in Lesson 3's memory calculator.
