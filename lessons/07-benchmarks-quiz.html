Take the benchmarks yourself, first

Before you ask a 1.5B model to answer these, answer them yourself. It's the fastest way to build intuition for what these scores actually mean — and to notice which question types are genuinely hard even for you.

The benchmark families behind these questions

BenchmarkStyle
MMLUBroad factual/academic knowledge, 4-way multiple choice
ARCGrade-school science reasoning, multiple choice
HellaSwag"What happens next" commonsense completion
GSM8KGrade-school math word problems

Now compare against the model

Ask your running model (from Lesson 05) each question exactly as worded below, and see if it agrees with you — and with the answer key. This is literally what an evaluation harness automates at scale: thousands of questions like these, scored automatically.

python -m mlx_lm.generate \
  --model mlx-community/Qwen2.5-1.5B-Instruct-4bit \
  --prompt "Question: Which of these is a renewable energy source? A) Coal B) Natural gas C) Solar power D) Petroleum. Answer with just the letter." \
  --max-tokens 10
