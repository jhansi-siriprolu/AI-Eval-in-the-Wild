Lesson 08 · Your real results

Your evaluation results dashboard

Run the harness, and this page will chart your actual numbers. Until then, it shows clearly-labeled sample data so you know what to expect.

Step 1 — run the real evaluation

bash scripts/04_run_eval_harness.sh

This installs lm-eval if needed and runs a handful of benchmark tasks against your model with a small sample limit (fast enough for a laptop — a few minutes rather than hours). It writes raw output to results/raw_eval_output.json.

Step 2 — shape it for this dashboard

python scripts/05_export_results.py

Converts the raw harness output into results/results.json in the simple shape this page reads. Then either:

  • Serve the folder locally so the chart auto-loads it: python -m http.server 8000 then open http://localhost:8000/lessons/08-results-dashboard.html, or
  • Just reload this file directly — if auto-load can't reach the JSON (browsers block fetch on local files), paste its contents into the box below instead.
